# Your Small Desk v0.1.0

Primera version instalable de Your Small Desk para Windows.

## Incluye

- Aplicacion de escritorio con Electron.
- PHP portable incluido para Windows.
- Base de datos local SQLite.
- Asistente de configuracion inicial.
- Datos de empresa personalizables.
- Logo personalizable para documentos.
- Gestion de clientes.
- Creacion de presupuestos.
- Exportacion a PDF.
- Estados de presupuesto.
- Resumen por trimestres.
- Manual integrado desde ajustes.
- Mailrelay opcional por API o SMTP.
- Licencia comunitaria de uso gratuito limitado.

## Instalacion

1. Descarga el instalador desde la Release.
2. Instala Your Small Desk.
3. Abre la app.
4. Completa el setup inicial.
5. Entra con el usuario creado.
